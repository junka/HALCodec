This folder consists of two header files NvEpl.h and SafetyServiceType.h which should be used by client applications on ccplex to report errors

1. NvEpl.h - Safety Services provide a NvEpl library to report errors to System Error handler (running on FSI). The library APIs are declared in NvEpl.h

2. SafetyServiceType.h - Contains exposed data type definitions which are used in error reporting

For more information please refer - PDK document.
